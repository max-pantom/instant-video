Introducing instant-video

An open-source hover player for the web. With a mouse, the first frame is decoded before the pointer arrives. Move sideways to scrub, and click to keep watching in the full player.

One command. Any host.

Point the encoder at a folder of videos and upload what comes out. No storage account needed.

# encode a folder into your static files
npx instant-video encode ./clips --out ./public/media --base-url /media

// drop it on any card
import { InstantVideoElement, type InstantSource } from 'instant-video'

const card = document.querySelector('.card')
const el = card?.querySelector('instant-video')
if (!card || !(el instanceof InstantVideoElement)) throw new Error('missing card')

el.source = await fetch('/media/clip.json').then((r) => r.json()) as InstantSource
card.onpointerenter = () => { el.active = true }
card.onpointerleave = () => { el.active = false }
